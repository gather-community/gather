# Translation glossary

Gather's terms, and the word chosen for each in every language. Translations use these so the same thing
has the same name everywhere. If you know a better word, change it here, then in the locale files (search
for the old word). See "Translations" in CLAUDE.md for how translated strings are written and marked.

## Voice

- Address the reader directly, in the form people expect from a friendly app: `vous` in French (both),
  `tú` in Spanish, `du` in German, `je` in Dutch, `tu` in Italian, and the ordinary (informal) forms in
  Swedish, Norwegian and Finnish.
- Keep it plain and short, like the English. Buttons are verbs (`Save`, `Enregistrer`, `Speichern`).
- Prefer gender-neutral wording (German `Küchenleitung` rather than `Koch/Köchin`). Don't use gender
  marks like `·`, `*` or `:` inside words.
- Canadian French (`fr-CA`) only overrides French where Québec usage differs (e.g. `quart` for a work shift,
  `courriel` for email). Everything else falls back to `fr`.
